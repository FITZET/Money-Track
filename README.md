# Money Track（钱迹）

一个简单、离线优先的 Android 记账与报销管理工具。

付款后选择类别，出差费用按事项归集，报销材料可以一键合并成 PDF。没有账号、没有广告，也不会把账单上传给开发者。

## 下载与安装

1. 打开 [最新版本下载页](https://github.com/FITZET/Money-Track/releases/latest)。
2. 下载 `MoneyTrack-版本号.apk`。
3. 在 Android 手机上打开 APK 并完成安装。系统如有提示，请允许浏览器或文件管理器“安装未知应用”。
4. 首次打开钱迹，按首页提示开启：
   - **通知使用权**：识别微信、支付宝和银行的支出通知。
   - **显示在其他应用上层**：付款后弹出分类卡片。
   - **通知权限**：悬浮窗不可用时发送分类提醒。

支持 Android 8.0 及以上版本。

部分小米、华为、OPPO、vivo 等手机还需要在系统设置中允许钱迹自启动，并把电池策略设为“不限制”。不要在系统设置中“强行停止”钱迹。

## 怎么用

### 日常记账

- 点击首页“记一笔”，填写金额、支出日期并选择类别；补录旧账会计入所选月份。
- 单笔超过 100 元会自动显示为重点开销。
- 类别可以新增或停用，之后记账会保留你的选择。
- “统计”页面可以查看每月各类别金额和占比，点击分类可查看每一笔明细。

### 付款后自动提醒

开启通知使用权和悬浮窗后，微信、支付宝或银行 App 发出付款通知时，钱迹会弹出分类卡片。点击“吃饭”“打车”等类别即可保存。

钱迹依赖付款 App 的系统通知。如果付款 App 没有发出包含金额的通知，可以手动记账。

### 管理报销

1. 在“报销”页面新建事项，例如“10 月上海出差”。
2. 记录打车、住宿、高铁等支出时关联该事项。
3. 可以逐笔勾选已报销，也可以勾选整个事项。
4. 已报销记录不会删除，可随时取消勾选恢复。

### 合并报销材料

- 每笔支出可以添加多张图片或多个 PDF。
- 进入报销事项，点击“合并并转发报销材料”。
- 勾选需要导出的支出后生成 PDF。
- 图片一张一页并自动适应 A4；原 PDF 会逐页合并。
- 生成后可以预览，或通过系统分享面板转发到微信等应用。

### 备份与换手机

1. 在首页进入“数据备份与换机”。
2. 旧手机点击“导出备份文件”，保存 `.mtbackup` 文件。
3. 把备份文件传到新手机。
4. 新手机安装钱迹，在同一页面点击“选择备份并恢复”。

备份包含账单、类别、报销事项和附件。`.mtbackup` 文件目前不加密，请保存在私人位置。

## 隐私

- 数据保存在手机的应用私有目录。
- 应用没有联网权限，也不包含广告或统计 SDK。
- 通知只在本机解析，不上传通知内容。
- Android 系统备份只在设备支持加密时启用。

详细说明见 [PRIVACY.md](PRIVACY.md)。安全问题请参考 [SECURITY.md](SECURITY.md)。

## 从源码构建

需要 Android Studio、Java 17 和 Android SDK 37。

```powershell
./gradlew.bat test assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/`。

## 版本与数据兼容

- 当前版本：`1.1.3`，`versionCode 5`。
- 每次发布必须递增 `versionCode` 并更新 `versionName`。
- 使用正式签名覆盖安装会保留并自动升级数据库，请勿为了更新先卸载旧版。
